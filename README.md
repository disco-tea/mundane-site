# Mundane — pre-launch landing page

A camera for the parts of your day you'd otherwise scroll past. No algorithm,
no ads, no feed engineered to hold your attention — just one small prompt a
day and the people you actually want to see it.

Static site, no build step. Open `index.html` directly or serve the folder:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
